# 🌍 Language Learning App

A simple and interactive **Language Learning App** built using **HTML, CSS, and JavaScript**. This project helps users learn and practice new vocabulary in an easy and engaging way.

## 🚀 Features

- 📖 Learn new words and their meanings
- 🎯 Interactive and beginner-friendly interface
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and lightweight application
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Language-Learning-App/
│── index.html
│── style.css
│── script.js
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
